# Starting templates (source included)
- `src/templates/AffiliateStorePage.tsx`: pass creator brand, headline and product array (see Product type). Affiliate links need relevant disclosures.
- `src/templates/CosmicLandingPage.tsx`: responsive astronomy/science starter with lazily loaded decorative 3D starfield; not a scientific simulator.
- `src/templates/SaaSLandingPage.tsx`: premium SaaS landing page with hero, features, and pricing components.

These templates are optional full-page React components, not separate runtime dependencies. Replace App.tsx with one template when starting a client project, or import into a router. Keep the master toolkit unchanged.
